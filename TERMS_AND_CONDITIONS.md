## 2. Service Description

Kasiku is a personal finance tracking application that allows users to:

- Record income, expenses, and transfers between financial assets
- Manage financial accounts across 11 asset types (cash, bank, e-wallet, savings, credit card, investment, crypto, property, vehicle, pension, receivable)
- Organize transactions with customizable categories
- Search and filter transactions by note, category, asset, type, and period
- Attach up to 5 photos per transaction from the camera or gallery (stored locally)
- View financial summaries, charts, reports, and local analytics (financial score, trends, projections, habit detection)
- Export data to CSV, Excel, and PDF formats, including analytics summaries to PDF
- Create and restore encrypted JSON backups (optionally protected by a PIN of your choice)
- Set recurring notification reminders
- Optionally lock the application with a 6-digit PIN and/or biometrics
- Use the interface in Indonesian or English with 6 currency options

**The Application** is a finance tracker that prioritizes local storage. Your financial data always remains on your own device. Kasiku does not sync your personal data to the cloud and does not connect to Yural Dev server infrastructure. However, the Application displays ads through **Google AdMob** (banner and interstitial), which requires an internet connection for ad delivery and, where required, Google's UMP consent form. No financial data is sent to the ad network.
