# Kebijakan Privasi

**Terakhir diperbarui: 13 November 2026**

## 1. Pendahuluan

Yural Dev ("kami", "milik kami", atau "kita") mengoperasikan Kasiku ("Aplikasi"), sebuah aplikasi pencatatan keuangan pribadi. Kebijakan Privasi ini menjelaskan bagaimana kami mengumpulkan, menggunakan, menyimpan, dan melindungi informasi Anda saat menggunakan Aplikasi ini.

Dengan menggunakan Kasiku, Anda menyetujui praktik yang dijelaskan dalam Kebijakan Privasi ini. Jika Anda tidak setuju, harap hentikan penggunaan Aplikasi.

## 2. Informasi yang Kami Kumpulkan

Kasiku dirancang sebagai **aplikasi yang mengutamakan privasi dan penyimpanan lokal**. Semua data keuangan Anda disimpan secara lokal di perangkat Anda. Kami **tidak** mengumpulkan, mentransmisikan, atau menyimpan data keuangan Anda di server eksternal.

### 2.2 Informasi yang Dikumpulkan Secara Otomatis

Kami **tidak** mengumpulkan data analitik penggunaan, laporan kerusakan, statistik penggunaan, atau data telemetri tentang cara Anda menggunakan Aplikasi. Fitur **Analitik** di dalam Aplikasi (skor keuangan, tren, deteksi kebiasaan, dan proyeksi) dihitung secara lokal dari data Anda dan tidak dikirim ke mana pun.

Kasiku menampilkan iklan yang dilayankan oleh **Google AdMob**. Untuk menyajikan iklan, Google Mobile Ads SDK dapat secara otomatis memproses informasi perangkat dan penggunaan standar tertentu, seperti:

- ID iklan (advertising ID) perangkat Anda (dapat diatur ulang melalui pengaturan perangkat)
- Alamat IP dan data lokasi umum (non-presisi), bila diizinkan oleh pilihan persetujuan Anda
- Model perangkat, versi sistem operasi, dan pengidentifikasi iklan
- Interaksi dengan iklan (misalnya, apakah iklan dilihat atau diklik)

Informasi ini dikumpulkan dan diproses oleh **Google**, bukan oleh Yural Dev, dan digunakan untuk menyajikan serta mengukur iklan sesuai dengan Kebijakan Privasi Google. Data keuangan Anda (transaksi, aset, kategori, catatan, foto, dan backup) **tidak pernah** dibagikan kepada Google atau jaringan iklan mana pun.

Di Wilayah Ekonomi Eropa (EEA), Inggris, dan Swiss, Aplikasi menggunakan **User Messaging Platform (UMP)** Google untuk meminta persetujuan Anda sebelum menampilkan iklan yang dipersonalisasi. Anda dapat mengubah atau menarik pilihan persetujuan kapan saja melalui pengaturan perangkat Anda.

Untuk informasi lebih lanjut tentang cara Google menangani data iklan dan cara memilih untuk tidak menerima, silakan tinjau:
- [Kebijakan Privasi Google](https://policies.google.com/privacy)
- [Setelan Iklan Google](https://adssettings.google.com)

### 2.3 Informasi dari Pihak Ketiga

Sebagaimana dijelaskan pada Bagian 2.2, SDK ini beroperasi di bawah kebijakan privasi Google sendiri dan tidak menerima data keuangan Anda. Kasiku tidak terintegrasi dengan layanan analitik, media sosial, atau pengumpulan cloud mana pun, dan tidak ada SDK lain yang mengumpulkan atau mentransmisikan data ke pihak ketiga.

Semua informasi yang disimpan di Kasiku digunakan semata-mata untuk menyediakan fitur-fitur Aplikasi:

- Merekam dan menampilkan transaksi keuangan

- Menjadwalkan notifikasi lokal untuk pengingat
- Menyimpan preferensi bahasa dan mata uang Anda
- Menampilkan iklan melalui Google AdMob (lihat Bagian 2.2)

## 4. Penyimpanan dan Keamanan Data

### 4.1 Lokasi Penyimpanan

Semua data keuangan disimpan secara lokal di perangkat Anda dalam:

- **Database SQLite** yang terletak di direktori data privat aplikasi, termasuk transaksi, aset, kategori, pengingat, preferensi, dan hash PIN kunci aplikasi
- **Sistem file lokal** untuk foto transaksi dan file backup di folder dokumen privat aplikasi

### 4.2 Keamanan Data

- Data Anda di database SQLite Aplikasi **tidak dienkripsi** saat disimpan di penyimpanan perangkat.
- Aplikasi menyediakan **kunci aplikasi opsional** berupa PIN 6 digit dan/atau biometrik. PIN disimpan sebagai hash SHA-256, bukan teks biasa. Setelah verifikasi berhasil, Aplikasi tetap terbuka selama **2 jam**; setelah itu verifikasi diperlukan kembali. PIN kunci aplikasi tidak dapat dipulihkan jika lupa.
- Kunci aplikasi adalah **kontrol akses**, bukan enkripsi database. Jika perangkat di-root, dimodifikasi, atau disusupi malware, data tetap berpotensi diakses. Kami menyarankan Anda mengaktifkan keamanan layar kunci perangkat Anda.
- **File backup dienkripsi secara default** menggunakan algoritma **AES-256-GCM**. Kunci enkripsi diturunkan dari PIN backup Anda (jika Anda memilihnya) atau rahasia bawaan yang tertanam di Aplikasi, menggunakan **PBKDF2-HMAC-SHA256 dengan 100.000 iterasi**.
- **Perlindungan PIN opsional**: saat membuat backup, Anda dapat memilih PIN 4–6 digit. Backup yang dilindungi PIN hanya dapat dipulihkan dengan memasukkan PIN tersebut; tanpa PIN, isi backup tidak dapat didekripsi. Kami tidak menyimpan PIN Anda di mana pun — jika Anda lupa, backup tidak dapat dipulihkan.
- Backup tanpa PIN tetap terenkripsi, tetapi kuncinya diturunkan dari rahasia yang tertanam di Aplikasi. Perlindungannya lebih rendah daripada backup ber-PIN; gunakan PIN backup untuk data yang sensitif.
- Backup menyertakan data keuangan, preferensi, dan pengaturan keamanan Aplikasi (termasuk hash PIN kunci aplikasi). Memulihkan backup dapat memulihkan pengaturan kunci aplikasi yang tersimpan di dalamnya. Backup **tidak** menyertakan foto transaksi atau pengingat.
- **Foto transaksi** disimpan di folder dokumen privat Aplikasi dan tidak diunggah, diekspor, atau disertakan dalam backup. Menghapus transaksi juga menghapus file fotonya.
- Dokumen yang diekspor (CSV, Excel, PDF) dibuat sebagai file teks biasa di sistem file perangkat Anda. Berhati-hatilah saat membagikan atau menyimpannya.

## 5. Berbagi dan Pengungkapan Data

### 5.1 Tidak Ada Berbagi dengan Pihak Ketiga

Kasiku **tidak membagikan, menjual, menyewakan, atau mengungkapkan data keuangan Anda kepada pihak ketiga mana pun**. Aplikasi tidak memiliki infrastruktur server, dan data keuangan Anda tidak pernah meninggalkan perangkat Anda — kecuali melalui tindakan yang Anda lakukan sendiri sebagaimana dijelaskan pada Bagian 5.2. Satu-satunya komunikasi jaringan pihak ketiga adalah pemuatan iklan melalui Google AdMob (lihat Bagian 2.2), yang tidak menerima data keuangan Anda.

### 5.2 Berbagi yang Diprakarsai Pengguna

Anda dapat memilih untuk membagikan data Anda melalui fitur-fitur berikut, yang memerlukan tindakan eksplisit Anda:

- **Backup**: Anda dapat membuat file backup JSON dan memilih untuk menyimpan atau membagikannya melalui dialog berbagi sistem. File backup menyertakan data keuangan, preferensi, dan pengaturan keamanan, tetapi tidak menyertakan foto transaksi atau pengingat.
- **Ekspor**: Anda dapat mengekspor transaksi sebagai file CSV, Excel, atau PDF, termasuk ringkasan analitik dalam PDF, dan membagikannya melalui dialog berbagi sistem. Foto transaksi tidak ikut diekspor.
- **Berbagi File**: Saat berbagi, file ditangani oleh lembar berbagi asli perangkat Anda dan tunduk pada praktik privasi aplikasi penerima.

### 5.3 Persyaratan Hukum

Jika kami diwajibkan oleh hukum (seperti perintah pengadilan atau panggilan pengadilan yang sah) untuk mengungkapkan informasi Anda, kami akan melakukan upaya yang wajar untuk memberi tahu Anda, kecuali dilarang oleh hukum. Karena kami tidak menyimpan data keuangan Anda di server kami, kami tidak memiliki data tersebut untuk diungkapkan.

## 6. Retensi dan Penghapusan Data

### 6.1 Retensi

Data Anda tetap berada di perangkat Anda selama Anda tetap menginstal Aplikasi dan memilih untuk menyimpan data. Aplikasi tidak memberlakukan batasan retensi data apa pun.

### 6.2 Penghapusan

Anda dapat menghapus data Anda dengan cara berikut:

- **Catatan individu**: Hapus transaksi, aset, kategori, atau pengingat individual melalui antarmuka Aplikasi. Menghapus transaksi juga menghapus foto terkait dari penyimpanan Aplikasi.
- **Hapus semua data**: Copot pemasangan Aplikasi atau hapus data Aplikasi melalui pengaturan perangkat untuk menghapus database, foto transaksi, dan preferensi lokal. File backup atau ekspor yang telah Anda simpan di luar penyimpanan Aplikasi mungkin tetap ada kecuali dihapus secara manual.
- **File backup**: Hapus file backup secara manual melalui layar Backup & Restore Aplikasi atau melalui pengelola file perangkat Anda.

### 6.3 Data Backup

File backup yang dibuat oleh Aplikasi dienkripsi (lihat Bagian 4.2) dan tetap berada di perangkat Anda hingga Anda menghapusnya secara manual. Aplikasi menyimpan riwayat backup yang dapat dibersihkan kapan saja. Menghapus riwayat backup juga menghapus file backup terkait dari penyimpanan internal Aplikasi.

## 9. Pengguna Internasional

Data Anda disimpan secara eksklusif di perangkat Anda dan tidak ditransfer lintas batas oleh kami. Namun, pemrosesan data iklan oleh Google dapat melibatkan transfer internasional sesuai dengan kebijakan dan pengamanan Google. Jika Anda memilih untuk membagikan atau mengekspor data, tindakan tersebut diprakarsai dan dikendalikan oleh Anda. Aplikasi tersedia di seluruh dunia dan mematuhi hukum privasi yang berlaku di yurisdiksi tempat penggunaannya, termasuk:

- **GDPR** (Wilayah Ekonomi Eropa)
- **CCPA/CPRA** (California, Amerika Serikat)
- **LGPD** (Brasil)
- **UU ITE** (Indonesia)
- **UU PDP** (Undang-Undang No. 27 Tahun 2022 tentang Perlindungan Data Pribadi)

## 10. Perubahan pada Kebijakan Privasi Ini

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu. Perubahan akan diposting di Aplikasi dan/atau di repositori Aplikasi. Tanggal "Terakhir diperbarui" di bagian atas kebijakan ini mencerminkan perubahan terbaru.

Perubahan material akan dikomunikasikan melalui Aplikasi dan/atau repositori Aplikasi. Penggunaan Aplikasi yang berkelanjutan setelah perubahan merupakan penerimaan kebijakan yang diperbarui.
